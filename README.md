# IoT Based Smart Water Quality Monitoring and Automatic Water Diversion System

## Team
Team Number: 30

## Project Description
This project monitors water quality using ESP32 and multiple sensors such as pH, TDS, turbidity, temperature, and water level. Based on predefined threshold values, the system automatically diverts clean water and muddy water using two solenoid valves. The sensor data is uploaded to ThingSpeak for real-time monitoring.

## Hardware Components
- ESP32
- pH Sensor
- TDS Sensor
- Turbidity Sensor
- DS18B20 Temperature Sensor
- Water Level Sensor
- Relay Module
- 2 Solenoid Valves
- Water Pump
- LCD Display

## Software
- Arduino IDE
- ThingSpeak
- GitHub

## Features
- Real-time water quality monitoring
- Automatic water diversion
- Cloud monitoring using ThingSpeak
- Threshold-based decision making
- ESP32 Wi-Fi connectivity
